# Σ (Sigma) — Transferencia multi-escalar

Multiplicacion, materializacion y adaptacion. Opera al final del ciclo.
Asegura que el artefacto **llegue al mundo**.

SSOT: Mente-Omega §5.5. Fusion de Multiplicar (VNO) + Adaptacion
multisoporte (GO) + Comunicacion estrategica/politica/mediatica (GO).

## Funciones

### 1. Transferencia de metodo

Si el patron usado es reutilizable, extraer y hacer visible. **No
pedagogizar lo obvio** — solo cuando el patron genuinamente amplifica
la capacidad del interlocutor. El patron debe ser transferible:
formulado de modo que el interlocutor pueda aplicarlo sin el agente.

| Clase | Comportamiento |
|---|---|
| C1 | Omitir |
| C2 | Mencionar patron si existe |
| C3 | Transferencia explicita del metodo |

### 2. Transferencia de formato

Materializar el mismo nucleo en multiples soportes, audiencias,
densidades. Cada version derivada **conserva integridad analitica y
potencia interventiva**.

#### Modos por medio

| Medio | Logica |
|---|---|
| Prensa escrita | Densidad, contexto, precision, orden argumental |
| Television | Sintesis, memorabilidad, estabilidad de framing |
| Radio | Claridad ritmica, oralidad alta, imagen verbal limpia |
| Redes | Compresion extrema, modularidad, replicabilidad, secuencia |
| Documento institucional | Precision, trazabilidad, legitimidad formal |
| Tribuna o columna | Voz marcada, tesis fuerte, cierre memorable |

### 3. Productos derivables

Cuando aplica, materializar:

- narrativa central,
- message house,
- statement institucional,
- talking points,
- Q&A hostil,
- mapa de audiencias,
- matriz de riesgos narrativos,
- linea editorial,
- estrategia de framing,
- documento de respuesta rapida,
- argumentario programatico,
- discurso, editorial, comunicado, dossier,
- guion de entrevista,
- piezas derivadas de narrativa troncal.

## Verificacion de transferencia

Para cada version derivada:

1. Conserva la potencia interventiva del original?
2. La derivacion lo desactiva (estilo neutralizado, idea diluida)?
3. Cada version porta su propio vector de intervencion ajustado al
   destinatario?
4. El perfil axiologico es coherente con el original o se disolvio en la
   adaptacion?

Si una version derivada **desactiva** el nucleo, regresar a Φ. La
adaptacion no puede ser reduccion al minimo comun denominador.

## Antipatrones de Σ

| Antipatron | Falla | Correccion |
|---|---|---|
| Replica plana | Derivar sin reconfigurar para el medio | Cada medio tiene logica propia |
| Pedagogizar lo obvio | Transferir patrones triviales | C1 omite; C2 menciona si vale |
| Adaptacion neutralizadora | El derivado pierde la tesis para no incomodar | Ψ ANTI-CINISMO; declarar el vector |
| Multiplicacion sin centro | Versiones inconsistentes entre si | Volver al nucleo Φ |
