# RPE N°9: Telemedicina

## Regla de admisión

Toda actividad debe existir en la cartera del establecimiento. Salud digital
busca acceso, menor espera/traslado/derivación, mayor resolución local,
continuidad, participación y transferencia de competencias. Requiere trabajo
integrado entre referentes y áreas del Servicio de Salud.

## Atención primaria

| Actividad | Rendimiento | Cobertura o condición |
|---|---:|---|
| Solicitud teleinterconsulta asincrónica médica/odontológica | 2–3/h | 100% demanda elegible; registro clínico con antecedentes, examen, hipótesis y adjuntos. |
| Apoyo terapéutico telegeriátrico multidisciplinario | 2–3/h | Personas ≥60 años, priorizando multimorbilidad, polifarmacia, demencia, deterioro o EMPAM alterado. |
| Entrega de indicaciones de teleinterconsulta | 3–4/h | 100% cursadas; diagnóstico, tratamiento, educación, derivación y registro local/digital. |
| Gestión remota de demanda | 6–8/h | Línea base 100% demanda previa; protocolo local. |
| Consulta abreviada remota | 10/h | Resultados, licencias o recetas. |
| Teleconsultoría de especialidad | 1/h | Sincrónica entre equipos; 100% planificación de red; excluye salud mental. |
| Teleconsulta profesional–paciente | 2–3/h | Sincrónica diagnóstica/terapéutica; puede incluir facilitador presencial. |
| Teleconsulta desde posta rural | 2/h | TENS solicita a Hospital Digital, ingresa, toma signos, presenta, acompaña, imprime, refuerza y entrega fármacos. |

Telegeriatría se articula con GES Demencia, Más Adultos Mayores Autovalentes,
Rehabilitación, Atención Domiciliaria, EMPAM y ECICEP, entre otros.

## Atención secundaria y terciaria

| Actividad | Rendimiento |
|---|---:|
| Solicitud asincrónica médica/odontológica | 3/h |
| Teleinterconsulta asincrónica especialista | 6/h |
| Teleinterconsulta sincrónica nueva / control | 3 / 4 por h |
| Teleconsulta profesional–paciente nueva o control | 4/h |
| Consulta abreviada remota | 10/h |
| Telecomité | 1/h |
| Teleconsultoría de especialidad | 1/h |

Solicitud asincrónica crea TeleSIC y registro; respuesta asincrónica genera
diagnóstico o plan. Teleinterconsulta sincrónica ocurre entre profesionales con
consentimiento. Teleconsulta ocurre con usuario y puede tener facilitador
presencial. Telecomité acuerda diagnóstico, tratamiento y continuidad.

Consulta nueva es primera atención de especialidad gestionada por SIC. Tras un
alta, una nueva necesidad requiere otra interconsulta. Control completa estudio,
tratamiento o seguimiento.

## Teleinformes

| Modalidad | Rendimiento |
|---|---:|
| Resonancia | 2/h |
| Tomografía | 2,5/h |
| Mamografía diagnóstica | 4/h |
| Mamografía tamizaje | 15/h |
| Fondo de ojo | 20/h |

Videollamada institucional es canal preferente; teléfono, excepcional.
Otros profesionales remiten a RPE 21; telerehabilitación, a RPE 14.
