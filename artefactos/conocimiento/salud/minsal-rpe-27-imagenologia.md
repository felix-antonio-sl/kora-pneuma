# RPE N°27: Imagenología secundaria y terciaria

## Regla de programación

Las actividades se homologan entre atención abierta, cerrada y Urgencia. Se
programa horario agendable ambulatorio en jornada hábil. Cerrada y Urgencia
dependen de demanda; rendimiento varía por equipo, infraestructura y cartera.

## Médico radiólogo

| Actividad | Rendimiento |
|---|---:|
| Interconsulta entre especialistas | 3/h |
| Pertinencia asincrónica | 4 pacientes/h |
| Consulta angiográfica con anamnesis/examen/plan | 3 pacientes/h |
| Neuro diagnóstico / intervencional | 0,5 / 0,3 estudios/h |
| Vascular periférico diagnóstico / intervencional | 0,4 / 0,7 estudios/h |
| Intervencional percutáneo | 0,7 estudios/h |
| Biopsia, estereotaxia u otro guiado | 1,3 estudios/h |
| US / Doppler / portátil | 3 / 2 / 1,5 estudios/h |
| US intraoperatoria | 0,5 pacientes/h |
| Radiología digestiva/fluoroscópica | 1,4 estudios/h |
| Informe RM / TC / Angio-TC | 2 / 2,5 / 2 estudios/h |
| Informe mamografía / densitometría / RX simple | 4 / 4 / 6 estudios/h |
| Informe PET-TC | 1 estudio/h |

US incluye exploración e informe; Doppler agrega evaluación vascular; portátil
se realiza en unidades críticas o emergencia; intraoperatoria apoya Pabellón.
Los informes entregan descripción e impresión diagnóstica.

## Tecnólogo médico

| Actividad | Rendimiento |
|---|---:|
| Neuro diagnóstico / intervencional | 0,4 / 0,2 estudios/h |
| Vascular periférico diagnóstico / intervencional | 0,5 / 0,8 estudios/h |
| Intervencional percutáneo | 0,8 estudios/h |
| Adquisición RM / TC / Angio-TC | 1,2 / 3,7 / 3 estudios/h |
| US / Doppler supervisado por radiólogo | 2 / 2 estudios/h |
| Mamografía / RX simple / densitometría | 4 / 6 / 3 estudios/h |
| Fluoroscopía en Pabellón | 0,8 pacientes/h |
| Biopsia estereotáxica mamográfica | 1,3 estudios/h |
| Radiología digestiva/fluoroscópica | 1,5 estudios/h |

Las actividades corresponden a adquisición de imágenes o apoyo técnico al
especialista según modalidad.
