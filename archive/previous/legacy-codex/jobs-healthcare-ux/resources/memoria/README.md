# Memoria

Fibra de memoria del agente `jobs-healthcare-ux`.

Esta carpeta reserva el espacio canonico para memoria de proyecto o agente cuando
un runtime la materialice. No debe contener secretos, datos de pacientes, dumps
runtime ni estado no gobernado. La fuente de verdad sigue siendo `AGENT.md`; la
memoria solo puede registrar aprendizajes operativos trazables y revisables.
